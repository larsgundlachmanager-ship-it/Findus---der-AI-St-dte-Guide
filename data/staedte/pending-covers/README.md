# Pending Stadt-Cover

User-Fotos, die **vor** der Stadt-Erstellung kommen, landen hier.

- `manifest.json` — Queue-Status (`queued` → `stylized` → `applied`)
- `<city_id>/source.*` — Original
- `<city_id>/stylized.png` — Kernrollen-Stil-Ausgabe

Commands: `npm run city:cover:queue` · `city:cover:pending` · `city:cover:apply`  
Skill: `.cursor/skills/findus-city-cover/SKILL.md`
